# Apple Design Layout Template

獨立的非地圖 UI／UX 預覽，對應 [優化分析](D:/FamilyTree/design/uiux-apple-audit-20261003.md)。使用示例資料，沒有引用 production runtime，也不存取現有 IndexedDB、族譜檔案或 Google Drive。

執行 `node design/apple-layout-template/serve.cjs`，開啟 [本機預覽](http://127.0.0.1:4198/)。也可直接開啟 `index.html`；場景切換由 iframe 的同來源訊息控制，建議用本機預覽伺服器。

頂部可以切換桌面、自訂 1024×768 的平板與 390×844 的手機視窗，並選擇族譜、成員清單、編輯表單、查關係與同步差異。

可試用：成員搜尋與狀態篩選、人物與親屬導覽、手機詳情收合、查詢與交換方向、表單選填展開、關係移除／恢復、取消時的未儲存提示、示例儲存／復原、更多功能、排行／合併預覽、版本差異與覆蓋角色、匯入預覽與示例匯出。表單更多提供「檢視最新資料」，展示保留草稿後的恢復選擇。

這是供確認效果的版面模板。族譜排列、稱謂計算、版本、同步、備份與合併均是示例邏輯，正式套用時必須接回既有 model／repository／版本檢查；不應將此模板直接替換 production。重新整理會重設示例修改。手機可拖曳詳情並未實作，提供點按收合替代。

已完成 JavaScript 語法檢查，以及瀏覽器中的桌面／平板／手機版面、清單搜尋、查詢結果、dirty 表單取消／繼續、示例儲存／復原、同步版本選擇的操作驗證。390×844 清單首列約在 y=272、列高62px、首屏完整九列（示例資料）。尚未驗證真實手機鍵盤、實體觸控與讀屏。

主要檔案：`index.html` 是預覽選擇器；`workspace.html`、`workspace.css`、`workspace.js` 是獨立介面；`serve.cjs` 只提供這些預覽檔案。
