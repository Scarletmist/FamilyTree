# 第五階段：整合驗收與發布檢查

日期：2026-10-12。狀態：本機整合回歸與發布包檢查完成；iOS／Android 實機與真實 Google OAuth 尚未驗收。這次完成本機可執行的整合流程及修正，沒有發布網站或改寫開發族譜。

## 實作內容

- `tests/run-phase5.cjs` 統一依序執行資料測試、全部 Node browser suites、16 個 Python UX suites、建置及發布包檢查。每項都有退出碼、時間及 log，另保存是否全量執行、開發族譜 SHA-256 比對結果及實機／OAuth 狀態。單項重跑可用 `PHASE5_SUITE_FILTER`；完整驗收先執行全量；失敗案例修正後，`PHASE5_RETRY_FAILED=1` 會核對正式程式與其他已通過測試未變更，再重跑失敗套件並保存先前報告／log。
- 修正重設後最近瀏覽鍵被寫回 `[]`、全圖導覽遮住桌面收合詳情、缺少 VisualViewport 時的導覽錯誤、桌面非模態成員清單無法用 Escape 關閉。
- 手機未設定關係的成員不再保留空白查詢按鈕；更多操作中的新增親屬與定位使用相同完整按鈕列。相同成員被背景定位或資料重繪時保留已開啟的更多選單，切換成員則關閉。
- 連線路由以既有長度與轉彎成本作為下限，提早略過不可能勝出的候選。成本、避讓及推導規則保持原本語意。
- 預覽／SVG 不再預先建立整份列印 HTML；開啟列印時才建立頁面。每頁保留會相交的線段與標籤，略過只有背景的頁面，重新連接頁碼及索引。A4 直式索引圖例維持與正文相同的縮放，避免字級低於名義 12pt。
- Python 測試依正式 HTML 的模組順序及 CSS 載入，遞迴處理 ES Modules；舊全域 API 僅存在於測試相容層。定位功能由真正靜態／API 的專屬 browser suites 驗證。介面斷言依目前的方向表單、詳情首屏、折疊欄位與更多選單更新，原生退場後才讀取隱藏狀態。
- `dev/check-release.cjs` 檢查瀏覽器儲存模式、相對資源及缺漏，拒絕 fixture、測試、開發腳本與 schema 備份。負向測試涵蓋資料外洩、遺漏及不支援專案子路徑的資源。手動 Pages workflow 在上傳前執行這項檢查。

## 效能與實際 PDF

`browser-phase5.cjs` 透過真正 `/repo/` 靜態網站量測 50／200／1000 位成員。合成資料由每組十人的小家族構成，限制手足推導的組內規模。量測包含寫入、模型與顯示投影、繪圖、兩個平移畫格、輸出預覽及實際列印視窗。每次數字保存於 `performance.json`；這是本機單次樣本，不是其他裝置的速度承諾。

| 成員數 | 寫入＋繪圖 | 輸出預覽 | 列印視窗 | 平移兩畫格 | 含索引列印頁數 |
| --- | --- | --- | --- | --- | --- |
| 50 | 0.16 秒 | 0.05 秒 | 0.09 秒 | 3.3 ms | 18 |
| 200 | 0.43 秒 | 0.13 秒 | 0.13 秒 | 14.4 ms | 106 |
| 1000 | 5.08 秒 | 1.44 秒 | 0.99 秒 | 38.6 ms | 1521 |

這組大型資料以完整字級列印仍會產生大量頁面。空白背景頁已略過，但連線跨度與保留字級仍決定頁數；分享大型族譜時宜使用 SVG，或先篩選家族／比較路徑再列印。此階段沒有改寫既有世代與連線排版演算法。

實際保存三份 PDF：A4 橫式 9 頁、A3 直式 4 頁、A4 直式隱藏姓名 6 頁，共 19 頁；已逐頁渲染並核對。文字檢查涵蓋所有應輸出的成員、80 字長姓名、封存銜接、待補節點、來源附錄、回收區／獨立封存省略、隱私、紙張與字級。名義正文 12pt 的 PDF 字級讀值約 11.9925pt，容許瀏覽器換算誤差。每頁另渲染 PNG，檢查卡片、連線、索引、跨頁及附錄；手機首屏與更多選單也保存三種尺寸截圖。

結果保存在 `.codebase-memory/phase5-results/`，包含 `report.json`、逐項 log、`performance.json`、`pdf-inspection.json`、三份 PDF、`pdf-pages/` 及手機截圖。這些測試產物與本機 Python 依賴已排除於 Git／發布包。
