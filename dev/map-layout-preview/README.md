# 成員地圖版面預覽

此樣板供確認 Apple Design 方向的版面與操作，獨立於正式網站。

直接以瀏覽器開啟 `index.html`，或執行 `node dev/map-layout-preview/serve.cjs`，再開啟終端輸出的本機網址。

- 上方可選擇桌面、手機直向、手機橫向，以及瀏覽、修正、最大縮放群組、尚未定位、底圖失敗情境。
- 點擊標記或清單地點，查看雙向選取；圖層選單提供底圖與群組設定。
- 點擊成員旁的修正圖示，在同一個工作區切換搜尋或中央準星指定位置。
- 手機面板把手可拖曳，或點擊切換收合、中間與展開高度。
- 群組內容在桌面以小面板呈現，手機直接列於底部面板。最大縮放仍可點擊查看。
- 儲存、恢復自動定位與復原只操作記憶體中的示範成員。

地圖為 SVG 示意，搜尋為示範候選；底圖切換只示範配色。未連接 Nominatim、Google、IndexedDB 或雲端同步。未完成正式地圖的動態、效能及實機鍵盤／手勢驗證。`screenshots/` 保存版面截圖供比較。
