## Why

「陳氏家族」族譜網站目前不存在，沒有任何對外的入口頁面。族譜的資料模型（領養、再婚、生卒年不確定、跨代收養）是這個專案真正困難的部分，若一開始就同時處理入口頁與資料模型，排版工作會拖慢資料模型的設計。先獨立交付一個不依賴任何族譜資料的靜態首頁，可以立刻建立網站門面，並讓資料模型的設計保留完整彈性。

## What Changes

- 新增單一檔案 `index.html`，作為「陳氏家族」族譜網站的首頁入口。
- 首頁包含五個區塊：Hero（家族名稱 + 一句話簡介 + 主要 CTA「瀏覽族譜」）、家族簡介（2–3 段文字）、數據列（世代數／成員數／最早紀錄年份，數值直接寫在 HTML 中）、三張入口卡（族譜圖、成員列表、家族相簿）、頁尾（聯絡方式、最後更新日期）。
- 樣式以 CSS 撰寫於 `index.html` 的 `<style>` 區塊內，不新增外部樣式檔、不引入前端框架、不引入 CSS 框架。
- 所有導向尚未存在頁面的連結（CTA 與三張入口卡）皆為佔位連結，指向 `#`，不會產生 404。

## Non-Goals

- **不建立族譜資料模型**：不定義成員、關係、世代的資料結構，不新增 JSON、SQLite 或任何資料來源。
- **不做族譜視覺化**：不繪製任何家族樹圖形，入口卡只是連結佔位。
- **不引入前端框架或建置工具**：不使用 React、Svelte、Next.js、Vite、npm 等。首頁沒有互動需求，框架選型應由後續的族譜視覺化需求決定，而非由首頁決定。
- **不做帳號、登入或權限**：首頁為公開唯讀內容。
- **不建立族譜圖、成員列表、家族相簿這三個子頁面**：本次僅提供入口卡與佔位連結。
- **不加入後端或伺服器**：`index.html` 以檔案方式在瀏覽器中直接開啟即可運作。
