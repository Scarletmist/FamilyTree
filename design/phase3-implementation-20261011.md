## 可信度與證據

`relationship-evidence.js` 提供每次渲染共用的索引、單筆／反向關係、手足／同門證據路徑及查詢路徑判斷。來源分為「直接記錄」「推導」；直接關係為「未標記／已確認／待確認」，推導為「依據未完整標記／依據已確認／依據待確認」。舊資料不補上 confirmed，pending 仍不參與自動親屬推導。

`relationship-evidence-view.js` 與 CSS 集中呈現狀態、涉及成員、原記錄位置、來源、說明及編輯入口。正反向多份記錄逐份列出；缺少證據保持未標記。原始資料更新時，開啟的證據視窗重新解析；被移除的關係顯示說明。關閉後還原焦點，原按鈕被重繪時尋找替代按鈕。

畫布保留原有親屬線型、箭頭與共用筆畫。標記分別對應婚姻、各子女對各家長、祖孫與輔助關係；多筆記錄逐筆列示，不把一位子女的狀態套到整組家庭。標記使用驚嘆號、勾號與未標記圓點，另有讀屏文字。低縮放總覽保留待確認警示與目前選取關係；其他狀態可從詳情查看。鍵盤聚焦可讀取完整說明，Enter／Space 與觸控可開啟證據。圖例以共用資料提供，供第四階段輸出沿用。

查詢保留原有多路徑選擇及稱謂規則，摘要標示目前路徑狀態，完整路徑逐段列出原始記錄。將原本「由已確認的親屬關係自動辨別」修正為「由既有親屬關係自動辨別」，避免把未標記資料當成已確認。

## 表單與手機

方向句與儲存仍使用同一個 parent／child 等欄位；快捷按鈕只設定原選單並觸發原變更流程。保留完整關係選單、雙向稱謂、類型、長幼、排行群組、來源及說明。草稿未標記狀態以空值保存，修正舊草稿序列化會把空值改成 confirmed 的問題。

手機姓名最多兩行，完整文字保留在標題與可存取名稱；操作維持 44px，長姓名不把按鈕擠出畫面。所在地、職位、排行群組與備註收於「成員資料與備註」。沿用收合／瀏覽／完整閱讀、拖曳中斷、背景 inert、焦點與返回政策。桌面仍完整顯示姓名及既有動作。

## 驗證與限制

- 全量 Node 測試 207 項通過：`node --test --test-concurrency=1 tests/*.test.cjs`。並行執行曾在不同本機 HTTP 測試出現 ECONNRESET，改為逐一執行後全部通過；未把失敗測試略過。
- `browser-phase3.cjs` 在靜態 IndexedDB／開發 API 各驗證 1440×900、390×844、360×640、844×390，共八個 context。涵蓋證據更新、鍵盤／觸控、八種方向實際儲存、反向 metadata、未標記草稿、親屬／待補預帶、80 字姓名、空狀態、封存標示、返回捲動、完整閱讀及拖曳展開／收合。
- 第二階段維護、關係政策／合併／模擬 Drive、自動推導、畫布動態、原生動畫與靜態儲存相關瀏覽器回歸通過；舊測試調整為正式入口與新的共用文案，仍檢查相同資料及操作結果。
- 使用隔離的族譜 JSON 與瀏覽器 context，外部服務使用模擬回應；工作區既有 fixture 升級及其備份保留。
- `node dev/build.cjs` 及 whitespace 檢查通過，正式 dist 包含新增資源，不包含示範族譜。

執行新流程：`node tests/browser-phase3.cjs` 或 `npm run test:phase3:browser`；Playwright 路徑與瀏覽器沿用 `PLAYWRIGHT_MODULE`、`PLAYWRIGHT_CHANNEL`、`PLAYWRIGHT_EXECUTABLE`。

手機尺寸、pointer 與可存取操作為瀏覽器模擬驗證。真實 iOS／Android 鍵盤、旋轉、工具列、安全區與觸控感受保留至第五階段實機驗收。第四階段的全圖導覽、SVG 與列印輸出尚未實作。
