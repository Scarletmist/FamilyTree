# 第四階段：導覽與輸出

日期：2026-10-11 至 2026-10-12。完成正式入口、共用場景、縮圖導覽、SVG 與瀏覽器列印流程；第五階段的手機實機、完整整合與發布驗收仍待執行。

## 可操作流程

- 更多功能 → 全圖導覽：桌面預設開啟、手機預設收合。顯示目前場景、可視框與選取人物；點擊定位、拖曳可視框、方向鍵平移、Home／適應畫面、返回目前人物。
- 更多功能 → 族譜輸出（SVG／PDF）：全家族、目前顯示範圍或目前比較路徑。比較輸出包含原路徑人物，不替換成不存在的直連。
- 可選封存成員、所在地、職位、關係來源與說明附錄。必要銜接人物保留並標示；回收區不輸出。
- 隱藏姓名時卡片使用 OOO，省略家族名稱、排行群組名稱與可能洩漏姓名的自由文字。真實姓名不藏在 SVG 屬性、title、附錄或列印文件。
- SVG 使用向量、完整文字、內含線段樣式與箭頭，沒有 foreignObject 或外部樣式依賴。長姓名與家族名稱換行。
- A4／A3、橫式／直式列印維持至少 12pt 正文，採分頁、導覽索引、頁碼、方向接續連結及至少 32px 重疊。邊界優先避開人物卡片；過高卡片無法避開時註明對照相鄰頁。多頁索引也分頁。
- 資料或設定更新會使預覽、下載與已開啟的列印視窗失效，更新預覽後才能再次輸出。列印頁不自動呼叫印表機，由使用者按列印／另存 PDF。

## 模組

| 模組 | 責任 |
| --- | --- |
| family-tree-diagram.mjs | 從原畫布抽出共用人物、端點、共享線段、路由、交叉橋與文字避讓；即時畫布和輸出共用 |
| family-tree-scene.mjs | 收集未縮放幾何、依實際記錄保留銜接人物、來源附錄 |
| family-tree-minimap.mjs | 縮圖幾何、定位／拖曳／鍵盤、視窗框與遮蔽處理 |
| family-tree-output.mjs | XML escaping、完整文字 SVG、紙張幾何與分頁／索引／列印文件 |
| family-tree-output-ui.mjs | 選項、預覽、版本保護、下載、列印視窗 |
| family-tree-navigation.css | 浮動導覽、手機輸出視窗、完整密度的離屏量測 |

畫布移動只更新視窗框；幾何場景改變才重建縮圖。導覽考慮目前畫布實際寬高、手機詳情與查詢摘要。完整閱讀、鍵盤、對話框或剩餘高度不足時暫時隱藏。縮圖操作阻止事件穿透。

既有確認狀態簡化、推導徽章與補填按鈕流程保持。父母資料完整的堂表親仍使用既有線段省略政策，沒有另加推導線。SVG／列印不修改 JSON、版本或復原歷史。

## 驗證

- 215 項 Node 測試通過，包含封存橋接、選取範圍、來源 escaping、隱私、四種紙張／方向分頁、安全邊界、長家族名稱及建置資源。
- 第四階段瀏覽器：靜態子路徑與隔離 API 資料，各測 1440×900、390×844、360×640、844×390。涵蓋縮圖鍵盤／點擊／拖曳、平移不重建、遮蔽、獨立 SVG、來源附錄、姓名隱藏、舊列印視窗失效及比較路徑。
- 桌面加測全家族／目前篩選範圍、包含封存、所在地／職位、A4／A3 橫直預覽。八組獨立 SVG 的姓名文字邊界均落在人物卡片內；已修正離屏姓名樣式的 specificity，讓量測及輸出同為 20px。
- 第三階段瀏覽器八組回歸通過，關係來源與推導徽章、表單方向、詳情首屏與返回流程保持。
- 實際產生 A4 橫式 PDF，包含 9 張族譜頁、1 張導覽索引及長來源附錄，共 15 頁。Poppler 渲染後檢查索引、頁首、人物卡片、接續及中文字體；pdfplumber 驗證完整 80 字姓名、必要封存人物、來源、尺寸及名義 12pt（抽取約 11.9925pt，為 Chromium 換算誤差）。
- 測試資料及 API 都使用隔離暫存檔，不寫入現有 fixtures。

測試命令：`node --test --test-concurrency=1 tests/*.test.cjs`、`node tests/browser-phase3.cjs`、`node tests/browser-phase4.cjs`、`node dev/build.cjs`。PDF 文字檢查：`python tests/phase4-pdf-inspect.py <測試PDF路徑>`，需要 pdfplumber。

## 效能與限制

50／200／1000 位合成幾何，縮圖建立 30 次取中位數及 p95；可視框更新 1000 次取每次平均。瀏覽器報告保存為產物目錄的 `phase4-performance.json`。

| 合成人數 | 縮圖建立中位數（代表性測量） | p95 | SVG＋分頁＋列印 HTML（單次） |
| --- | --- | --- | --- |
| 50 | 約 0.2 ms | 約 0.4 ms | 約 1 ms |
| 200 | 約 0.9 ms | 約 1.3 ms | 約 8.4 ms |
| 1000 | 約 3.3 ms | 約 4.1 ms | 約 114 ms |

1000 位縮图保留 1000 個人物矩形，省略連線；200 位仍保留簡化連線。可視框更新約 0.001–0.003 ms，與整圖人數無關。這些數字是桌面 Edge 的幾何 DOM／序列化測量，不包含原資料的推導、完整布局、瀏覽器繪製、印表機或真實手機速度。門檻採保守的 200 位，後續以實機與真實大型族譜調整。

手機測試是桌面瀏覽器尺寸／觸控模擬；iOS Safari、Android Chrome 實機的旋轉、鍵盤、safe-area 和列印行為，以及其他瀏覽器的 PDF 匯出，列於第五階段。未執行正式發布或遠端部署。
