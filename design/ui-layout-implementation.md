# Layout 實作記錄 — 2026-09-30

保留既有資料、關係線型與節點幾何。實作工具列分組、中寬查詢 dialog、可收合的桌面詳情佔位、視覺 token 與一致的按鈕尺寸。

- 主要文字按鈕基準高度 44px；純 icon 控制 44×44px、SVG 20px。長文字與多行狀態允許增高。
- 更多操作沿用相同 dialog 與既有處理程序；各版型只顯示一個入口。
- 一般桌面（寬度超過 700px 且高度超過 520px，或寬度超過 950px）展開詳情時，保留 336–360px 右側空間；手機與低高度橫向沿用原適配。
- 中寬查詢 dialog 採兩個選人欄位與側邊交換控制，方向問句依文字高度排列；不顯示屬於畫布的顯示全部／姓名控制。
- 畫布監看詳情造成的寬度變化，保留切換前選取錨點；查詢適配新的可用寬度，退出仍還原原全圖視角。虛擬鍵盤與視窗 resize 沿用既有 coordinator 行為。

驗證：118 項 Node 測試；12 種尺寸的 action layout 測試（含單一 More、44px／20px 尺寸、長姓名、query dialog 高度、桌面佔位、收合錨點、退出查詢還原、資料不被 UI 操作修改）；靜態子路徑／IndexedDB／匯入匯出／跨分頁衝突測試；API 與靜態模式關係管理、復原、搜尋浮層及模擬 Google Drive 衝突測試；靜態 build。

既有整合測試已改用現行 FamilyApp、FamilyRepository 語意方法與 familytreeselect 事件，並修正測試伺服器的 CSS／ES module MIME，未為測試恢復舊的 production 全域變數。真實手機鍵盤與 Google 帳戶授權未在此次測試中驗證。
